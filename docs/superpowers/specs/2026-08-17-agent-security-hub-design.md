# Agent Security Hub — Design

> Date: 2026-08-17
> Status: 已批准（2026-08-17）
> 项目路径：`~/Projects/agent-security-hub/`

## 1. 目标

创建一个 **Agent 安全知识库 + 分享项目**，用于：

1. **整合现有调研成果**——将《AI Agent 领域安全挑战与应对方法调研》报告作为种子内容拆解入库
2. **持续收录 Agent 安全信息**——按对象类型分类的事件/漏洞/厂商/论文/工具库，带新增模板
3. **提供 Agent 安全评估模型**——风险打分模型 + 安全成熟度模型（双模型）
4. **输出 30 分钟分享会文档**——面向混合受众（技术 + 管理）

## 2. 定位与约束

- **纯 Markdown 知识库**，零依赖、无构建、无测试（仿 `~/Projects/agent-design` 风格）
- 一致性靠**结构约定**（各库固定字段模板）而非代码强制
- 内容原则：数据有事实依据、区分事实/估算/建议、标注检索日期

## 4. 核心组件设计

### 4.1 评估模型（双模型）

**风险评估打分模型**（`docs/evaluation/risk-score.md`）
- 基于报告 1.7 的 17 向量 L×I 矩阵
- 扩展内容：
  - **评分指引**：谁用（安全/架构/采购）、评估对象（候选 agent 方案）、怎么定 I 值（资产/影响清单）
  - 使用步骤：识别向量 → 定 L（可能性）→ 定 I（影响）→ 查矩阵 → 处置建议
  - 示例：完整打分演示
- 保留报告既有数据（来源、校准基线、数据缺口）

**安全成熟度模型**（`docs/evaluation/maturity-model.md`）
- CMMI 风格 0-5 级
- 5 个维度：治理 / 架构 / 护栏 / 监控 / 供应链
- 每级含：行为描述 + 证据要求
- 使用指引：如何定位当前等级、如何推进

### 4.2 30 分钟分享会文档（`docs/presentation-30min.md`）

混合受众结构（分节标注建议用时 + 讲者备注）：

| 节 | 内容 | 建议用时 |
|----|------|---------|
| 1. 开场 | 为什么 agent 安全重要（趋势数据） | 2 min |
| 2. 风险全景 | 17 向量概览 + 致命三角（通俗版） | 6 min |
| 3. 真实案例 | 3-4 起事件（技术细节 + 影响金额） | 6 min |
| 4. 防御框架 | 纵深防御 + 最小权限（管理层视角的"该做什么"） | 6 min |
| 5. 评估模型 | 双模型演示（如何判断"我的 agent 安不安全"） | 6 min |
| 6. 行动建议 | 落地清单 + 资源指向 | 4 min |

### 4.3 知识库（按对象类型）

**种子内容来源**：现有报告 8 章拆解映射：

| 知识库 | 种子内容来源 |
|--------|------------|
| reports/ | 完整报告（含概览导航 + 核验表） |
| incidents/ | 4.1 事件案例（18 起）+ 4.2 研究演示 |
| vulnerabilities/ | 01 章 1.3/1.4 的 CVE（CVE-2025-6514/32711/59528/27876 等）+ 09 章 IOC 相关 |
| vendors/ | 4.3/4.6 厂商生态、并购、融资、定位 |
| papers/ | 4.2 论文 + 3.5 基准（AgentDojo/MCPTox 等） |
| tools/ | 2.8 工具生态 + 2.9/2.10 检测与防护资产 |

**新增模板**：每库一个 `_template.md`，固定字段（如事件库：时间/类型/影响/来源/核验状态）。

## 5. 数据流与维护

- 新增信息 → 按对应库模板填入
- 研究报告中引用的核验表（V1-V79）作为**全局参考**保留在 reports/
- 评估模型与知识库内容联动（风险评分引用 incidents/vulnerabilities 数据）

## 6. 验收标准

1. 项目结构完整，README 导航清晰
2. 双评估模型可用（有指引 + 示例）
3. 知识库六库齐全，种子内容已拆解入库，每库有新增模板
4. 分享会文档可支撑 30 分钟演讲（分节 + 讲者备注）
5. 所有内容延续事实核验纪律（来源可溯、区分事实/估算）

## 7. 非目标（YAGNI）

- 不做自动采集（后续可扩展 MCP 搜索）
- 不做静态网站生成
- 不做数据库/查询系统
